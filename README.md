<h2>프로젝트 소개</h2>
<P>API를 활용하여 키워드, 장소 검색으로 주변 음식점을 찾는 웹 사이트</P>

<h2>주요 기능</h2>
<span>
    • 소셜 로그인/로그아웃(카카오)<br>
    • 키워드로 음식점 검색><br>
    • 장소로 음식점 검색<br>
    • 현재 위치 찾기<br>
    • 음식점 정보 모달창<br>
</span>

### `npm install`
### `npm start`
